# 착지 충격 랩

달리기·점프 영상을 올리면 관절을 추적해 **착지 순간**을 찾고, 무게중심이 얼마나 빠르게 멈추는지를 바탕으로 충격을 가늠합니다.

힘판 측정이 아닙니다. 카메라 한 대의 2D 추정이며 의료 진단이나 훈련 처방이 아닙니다.

## 무엇을 보나요

- **접지 / 체공 시간**: 한 발이 땅에 붙어 있는 시간과 두 발이 모두 떠 있는 시간
- **추정 최대 지면반력 (BW)**: 접지 시간이 짧고 체공이 길수록 큰 힘이 실린다는
  충격량 관계로부터 체중의 몇 배인지 환산. 느린 조깅은 2 BW 안팎, 스프린트는
  3.5 BW 이상으로 갈립니다
- **페이스 대역**: 듀티 팩터(접지 시간 / 스트라이드 시간)로 걷기부터 스프린트까지 구분
- **착지 속도**: 발이 닿기 직전 무게중심의 수직 속도
- **등가 낙하 높이**: 같은 속도를 내려올 때 해당하는 높이
- **충격 점수 (0–100)**: 반력, 부하율, 무릎이 얼마나 펴진 채 받았는지를 합친 휴리스틱
- **부담 패턴과 훈련 제안**: 정강이·발, 무릎·고관절에 부담이 커질 수 있는
  측정 패턴을 설명하고 단계적인 자세·근력 훈련을 제안
- **영상 전체 요약**: 프레임마다 잡은 착지를 모아 평균 충격, 케이던스, 좌우 차이, 반복되는 부담 패턴을 한 글로 정리

점수가 낮을수록 충격을 나눠 받은 착지에 가깝고, 높을수록 짧고 뻣뻣한 착지에 가깝습니다.
부담 부위는 부상 예측이나 진단이 아니며, 통증·부종·절뚝거림이 있으면 영상 결과와
관계없이 스포츠의학 전문가의 평가가 우선입니다.

## 촬영 팁

- 전신이 나오게, 가능하면 **옆모습**
- 카메라 고정, 밝은 조명
- 점프 후 착지 또는 제자리 구보처럼 발이 떨어졌다 닿는 장면
- 앞 18초만 분석합니다

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43217](http://127.0.0.1:43217) 을 엽니다.

자세 추정은 [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)를 브라우저에서 돌립니다. 영상은 서버로 올라가지 않습니다.
