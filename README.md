# 착지 충격 랩

달리기·점프 영상을 올리면 관절을 추적해 **착지 순간**을 찾고, 무게중심이 얼마나 빠르게 멈추는지를 바탕으로 충격을 가늠합니다.

힘판 측정이 아닙니다. 카메라 한 대의 2D 추정이며 의료 진단이나 훈련 처방이 아닙니다.

## 무엇을 보나요

- **접지 / 체공 시간**: 한 발이 땅에 붙어 있는 시간과 두 발이 모두 떠 있는 시간
- **추정 최대 지면반력 (BW)**: 듀티 팩터로부터 환산합니다. 스탠스를 완전한
  반사인으로 보면 값이 지나치게 치솟으므로, 보고된 실측 최대값(느린 조깅 약
  2.1 BW, 편한 러닝 약 2.4 BW, 스프린트 약 3.7 BW)에 맞춘 곡선을 씁니다
- **페이스 대역**: 듀티 팩터(접지 시간 / 스트라이드 시간)로 걷기부터 스프린트까지 구분
- **착지 주법**: 첫 접지 프레임에서 뒤꿈치–발가락 각도를 발 길이로 정규화해
  리어풋(뒤꿈치가 먼저), 미드풋(거의 수평), 포어풋(앞꿈치가 먼저)으로 분류하고
  영상 전체 비율을 표시
- **몸 앞 착지 (오버스트라이딩)**: 첫 접지 순간 발목이 엉덩이보다 얼마나 앞에
  있었는지를 cm 와 신장 대비 %로 봅니다. 진행 방향은 발이 가리키는 쪽(발가락−뒤꿈치)에서
  읽으므로 카메라가 패닝해도, 왼쪽으로 달려도 같은 값이 나옵니다. **러닝에서 합의된
  경계가 없어 좋다·나쁘다를 판정하지 않고 거리만 표시합니다.**
- **정면에서 본 좌우 정렬**: 정면·후면으로 찍힌 영상은 거부하지 않고 다른 항목을
  봅니다. 지지 구간에서 무릎이 발–엉덩이 선 안쪽으로 얼마나 들어가는지, 디딘 발
  반대쪽 골반이 얼마나 내려가는지를 각도로 잽니다. **러닝에서 검증된 경계가 없어
  각도만 재고 판정하지 않습니다.** 대신 좌우 차이는 같은 영상 안의 비교라 절대
  기준 없이도 볼 수 있습니다
- **착지 속도**: 발이 닿기 직전 무게중심의 수직 속도
- **등가 낙하 높이**: 같은 속도를 내려올 때 해당하는 높이
- **충격 점수 (0–100)**: 반력, 부하율, 무릎이 얼마나 펴진 채 받았는지를 합친 휴리스틱. 짧은 접지는 페이스이지 점수를 올리는 항목이 아닙니다.
- **부담 패턴과 훈련 제안**: 정강이·발, 무릎·고관절에 부담이 커질 수 있는
  측정 패턴을 설명하고 단계적인 자세·근력 훈련을 제안
- **지금 이 순간**: 분석 후 영상을 재생하면 오른쪽 칸이 접지·체공·무릎을 따라갑니다. 자세가 펴졌는지, 깊게 굽었는지를 그 프레임에서 봅니다.
- **러닝화 추천**: 착지 주법이 정해지면 나이키·아식스·아디다스를 먼저 고르고, 같은 주법의 다른 브랜드는 다음 순위로 둡니다
- **이 착지 저장**: 고른 착지 한 장을 PNG로 내려받습니다. 프레임 위에 관절선과
  그 착지의 숫자, 그리고 2D 추정이라는 문구가 함께 찍힙니다. 옆모습이면 주법과
  몸 앞 착지가, 정면이면 무릎 정렬과 골반 기울기가 들어가며 화면과 같은 규칙을
  따릅니다 — 품질이 부족한 영상은 이미지에도 숫자를 넣지 않습니다

점수가 낮을수록 충격을 나눠 받은 착지에 가깝고, 높을수록 짧고 뻣뻣한 착지에 가깝습니다.
부담 부위는 부상 예측이나 진단이 아니며, 통증·부종·절뚝거림이 있으면 영상 결과와
관계없이 스포츠의학 전문가의 평가가 우선입니다.

영상만으로 수평 속도는 알 수 없습니다. 카메라 패닝과 원근 때문에 화면 이동량이
실제 m/s가 아니기 때문입니다. 실제 분/km 페이스를 알면 입력하는 것이 가장 정확하며,
입력하지 않은 경우에만 접지·체공 비율로 페이스 대역을 추정합니다.

정면 영상에서는 무릎 굽힘을 내지 않습니다. 무릎이 카메라 축 방향으로 굽어 이미지
평면의 각도가 실제 굽힘이 아니기 때문이며, 충격 점수도 그 항목을 빼고 나머지를
다시 100점으로 폅니다. 없는 값을 기본값으로 메우지 않습니다.

사람이 화면 높이의 20%보다 작거나 자세가 75% 미만 구간에서만 잡히면 충격량을
숫자로 표시하지 않습니다. 불확실한 영상에서 임의의 높은 수치를 내는 것보다 재촬영을
요청하는 것이 안전합니다.

## 촬영 팁

- 전신이 나오게. **옆모습**이면 착지 주법·몸 앞 착지·무릎 굽힘을, **정면·후면**이면
  좌우 정렬을 봅니다. 접지·체공 시간과 추정 반력, 케이던스는 어느 쪽이든 나옵니다
- 카메라 고정, 밝은 조명
- 점프 후 착지 또는 제자리 구보처럼 발이 떨어졌다 닿는 장면
- 앞 18초만 분석합니다

## 실행

```bash
npm install
npm run dev
npm run test:analysis
npm run check:language
```

판정 경계값은 `shared/thresholds.yaml` 한 곳에 모여 있고, 값마다 근거와 검증 상태를
답니다. 화면의 **판정 근거** 카드가 그 표를 그대로 보여 줍니다. 러닝에서 검증된
기준이 없는 값(`withheld`)에는 판정을 붙이지 않고 측정값만 내보냅니다.
`npm run emit:thresholds` 로 생성 파일을 다시 쓰며, 어긋나면 테스트가 실패합니다.

주법 판정·브랜드 순위·금지어 검사는 `src/lib/Footstrike.ts`, `src/lib/Shoeranking.ts`, `scripts/check-language.mjs` 입니다. 설명은 `src/lib/Readme.md`에 있습니다. 브라우저에서는 [http://127.0.0.1:43217/downloads](http://127.0.0.1:43217/downloads) 에서 받을 수 있습니다.

브라우저에서 [http://127.0.0.1:43217](http://127.0.0.1:43217) 을 엽니다.

자세 추정은 [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)를 브라우저에서 돌립니다. 영상은 서버로 올라가지 않습니다.

화면 미리보기와 내려받는 이미지 모두 얼굴을 블러로 덮습니다. 머리를 감싸는 타원으로 자르고 반경은 얼굴 폭에 비례하므로, 해상도가 달라져도 세기가 같습니다. 기본값은 켬이고,
영상 아래 **얼굴 가림 / 얼굴 보임** 버튼으로 끕니다 — 본인 자세를 자세히 볼 때는
끄고, 화면을 공유하거나 녹화할 때는 켜 두세요. 이 버튼 하나가 미리보기와 저장
이미지 양쪽을 함께 결정하고, 끈 채로 저장하면 이미지에 그렇게 적힙니다. 영상이 기기 밖으로 나가지 않는다는
점은 그대로이고, 이미지는 앱이 만드는 것 중 **밖으로 나갈 수 있는 첫 파일**이라서
넣은 장치입니다. 얼굴 위치는 이미 추적 중인 포즈 랜드마크(코·눈·귀·입)에서 찾고,
못 찾으면 앞뒤 프레임에서 다시 찾고, 그래도 없으면 화면 위쪽 1/3을 통째로 덮으며,
그마저 못 하면 이미지를 만들지 않습니다. 카메라로 찍는 중이거나 영상을 고르고 아직
분석하지 않았을 때는 랜드마크가 없으므로, 얼굴만 초당 네 번쯤 따로 찾아 덮습니다 —
그래야 화면 위쪽을 통째로 가리지 않고도 프레임을 잡거나 영상을 훑어볼 수 있습니다.
가리는 범위는 머리보다 조금 넉넉합니다. 옆모습에서는 먼 쪽 눈과 귀가 사라져 랜드마크
폭이 절반이 되는데, 코와 어깨 사이 거리로 머리 크기를 따로 재서 박스가 같이 줄지
않게 했습니다.
## 촬영 배속

기본값은 **8배**입니다. 휴대폰 슬로우 모션(240fps)으로 찍은 영상을 기준으로 합니다.

일반 속도로 찍었다면 반드시 바꿔야 합니다. 배속이 실제와 다르면 접지·체공 시간과
케이던스가 그 배수만큼 어긋납니다. 다만 듀티 팩터는 시간의 비율이므로 배속이
틀려도 값 자체는 유지되며, 대신 접지 구간이 사람의 범위를 벗어나 착지를 놓치게 됩니다.

배속이 어긋나면 사람이 낼 수 없는 보행이 되므로, 품질을 측정 불가로 내리고
접지·반력·주법 숫자를 비웁니다. 맞는 배속을 제안하고 한 번에 다시 분석할 수
있게 합니다.

## 착지 주법 판정 조건

- 가능하면 **정확한 옆모습**에서 발 전체가 보여야 합니다.
- 접지 순간 발바닥 각도가 -8° 이하이면 리어풋, -8°~+8°이면 미드풋,
  +8° 이상이면 포어풋으로 분류합니다(화면 아래쪽이 양수).
- 40°를 넘는 값은 반대쪽 발 가림이나 랜드마크 오류로 보고 제외합니다.
- 알려진 착지의 60% 이상이 한 유형일 때만 대표 주법으로 부릅니다. 아니면 혼합형입니다.
- 어느 한 착지 주법이 보편적으로 더 안전하거나 좋은 것은 아닙니다. 억지로 포어풋으로
  바꾸면 종아리·아킬레스 부하가 갑자기 늘 수 있습니다.
